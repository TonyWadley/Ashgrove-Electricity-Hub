# Ashgrove Electricity Hub

Agile Import Advisor — shows Octopus Agile import prices alongside the next day's weather and recommends the best times to import electricity (cheapest windows, plunge pricing, battery charging plan, solar estimate).

- Prices: Octopus Energy public API (Agile, inc. VAT)
- Weather: Open-Meteo
- Postcode lookup: postcodes.io

Single static page (`index.html`), no build step. Settings are stored in your browser.
